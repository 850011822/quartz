# 关于这个站点

## 这是什么

**知识工程实验室**是 Xiang 的公开第二大脑，用 [[public-second-brain|公开第二大脑]] 的思路运营——不是博客，不是完成品展示，是一个**持续生长的思考记录**。

站点基于 [[obsidian-ecosystem|Obsidian]] + Quartz 4 构建，原始 vault 在本地持续维护，公开部分自动同步发布。

---

## 这个知识库的结构

Vault 采用 PARA 变体组织：

| 区块 | 内容 |
|------|------|
| **Projects（项目）** | 有明确目标的执行中任务，如 AI-Knowledge-System |
| **Areas（领域）** | 长期维护的能力区，如 AI 工程、量化投资 |
| **Knowledge（知识）** | 结构化概念库，核心是 LLM-Wiki |
| **Outputs（产出）** | 公开发布的内容，包括本站 |

→ 详见 [[主题导航]]

## LLM-Wiki 是什么

[[llm-wiki|LLM Wiki]] 是这个站点最核心的知识层。

它不是普通笔记：原始资料投入 `raw/`，由 AI agent 持续编译成结构化的概念页。每页都有：
- 精确定义
- 与其他概念的双向链接
- 来源引用
- 状态标记（draft / stable / outdated）

这个模式来自 Karpathy 的设想——把知识库当成可持续编译的文档，而不是静态笔记堆。

→ [[三层架构-raw-wiki-schema|三层架构：Raw / Wiki / Schema]]

## 哪些内容是公开的

公开范围刻意保持**精选**，不是全量 dump：

- **LLM-Wiki wiki 页**：全量，每页经过 agent 编译和人工审查
- **元工程框架 v2**：最核心的方法论文档，公开供参考
- **导航页（本站）**：index、about、开始这里、主题导航

私有内容（项目细节、个人日记、草稿）保留在本地 vault，不发布。
