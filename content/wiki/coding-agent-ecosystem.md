# Coding Agent Ecosystem

## 一句话定义

Coding agent ecosystem 指的是围绕 Cursor、Windsurf、Cline、Claude Code 等工具形成的新一代 AI 编程环境：它们不再只做补全，而是开始接管多步执行、工具调用、上下文检索和项目级规则。

## 生态正在发生什么变化

从 2023-2024 的 autocomplete / chat IDE，逐步走向：

- project-wide context retrieval
- terminal / tool integration
- multi-step agent loops
- rules / memory / MCP support
- 成本、模型和权限控制

## 几个代表的常见气质

- **Cursor**：编辑器增强和 AI 工作流融合较深
- **Windsurf**：更突出 agent 回路、上下文检索和 IDE-native orchestration
- **Cline**：更开放、更可配置，也更依赖 power-user 调教

## 真正的比较维度

不是谁"更聪明"，而是：

- 上下文拿得准不准
- 工具集成深不深
- 规则系统够不够稳
- 人是否还能保持控制感
- 成本与自治性是否平衡
