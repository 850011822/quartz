# MOC (Map of Content)

## 一句话定义

Nick Milo 在 LYT 框架中提出的概念：一种**动态枢纽笔记**，以非线性方式组织和连接相关想法——不是静态文件夹，而是随知识增长而演化的"思想地图"。

## 和 Structure Note 的关系

MOC 是 [[structure-note|Zettelkasten Structure Note]] 的现代演化版本：

| 维度 | Structure Note (Zettelkasten) | MOC (LYT) |
| ---- | ---- | ---- |
| 来源 | Luhmann 的 hub notes | Nick Milo 的 LYT 框架 |
| 功能 | 导航枢纽 | 导航枢纽 + 思考工具 |
| 动态性 | 需要手动维护 | 强调"活的文档"，持续演化 |
| 工具 | 原始 Zettelkasten（纸卡片） | Obsidian / Roam / Logseq |
| 结构 | 层级 + 序列 | 非线性，混合多种组织方式 |

**核心相同点**：都是元笔记（meta-note），不记录一手知识，而是组织其他笔记之间的关系。

## MOC 的特征

1. **动态而非静态**——随着新笔记的加入而生长
2. **多层级**——MOC 可以链接到其他 MOC，形成层级结构
3. **非线性**——不强制线性阅读顺序，而是提供多条探索路径
4. **双向的**——通过 backlinks，笔记自然聚集到相关的 MOC

## 本 LLM-Wiki 中的 MOC 实践

本系统的 [[index|index.md]] 就是一个 MOC——它组织所有 wiki 页面的关系和导航路径。

在 LLM Wiki 语境下，MOC 的维护可以被自动化：每次 ingest 后，LLM 自动更新 index。
