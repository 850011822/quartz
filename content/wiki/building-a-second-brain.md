# Building a Second Brain (BASB)

## 一句话定义

Tiago Forte 提出的个人知识管理方法论：通过一个外部数字系统（"第二大脑"）捕获、组织、提炼、表达信息，把输入转化为创造性产出。

## CODE 方法

BASB 的核心操作框架是 **CODE**：

| 步骤 | 含义 | 关键行动 |
| ---- | ---- | -------- |
| **C**apture | 捕获 | 只保留"共鸣"的信息；像策展人一样思考 |
| **O**rganize | 组织 | 按可行动性分类，使用 [[PARA方法]] |
| **D**istill | 提炼 | [[progressive-summarization\|渐进式摘要]]——分层压缩，为未来的自己服务 |
| **E**xpress | 表达 | 把知识转化为现实世界的创造性产出 |

## 核心洞见

- **不要优化自己，优化外部系统**——"It has you optimize an external system that is more reliable than you will ever be."
- **Intermediate Packets**——把大项目拆成可复用的小块，每个小块本身就有价值
- **共鸣过滤**——捕获决策不应该是高度理性分析的，而是凭直觉"这让我有感觉"
