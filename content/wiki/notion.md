# Notion

## 一句话定义

Notion 是一个以协作工作区、数据库视图和权限体系为核心的云端文档平台；与 Obsidian 相比，它更像团队工作空间，而不是本地优先的个人知识写作环境。

## 它的强项

- databases / properties / views
- sharing & permissions
- 协作文档与项目管理
- 一个 workspace 里同时做知识库、项目、任务与文档

## Notion vs Obsidian 的核心差异

| 维度 | Notion | Obsidian |
| ---- | ------ | -------- |
| 数据抽象 | database / object / view | markdown file / wikilink |
| 协作 | 原生强 | 依赖外部同步与工具 |
| 本地控制 | 较弱 | 强 |
| 可编程扩展 | API + 模板 | 插件 + 本地文件生态 |
| 知识组织气质 | workspace / docs database | personal knowledge graph |

## 为什么很多人两者并用

因为它们常分工明确：

- Notion 负责团队协作、共享流程和项目视图
- Obsidian 负责个人写作、思考、长期知识积累

## 和其他概念的关系

- [[obsidian-ecosystem]] — Obsidian 的优势往往来自本地优先和插件生态
- [[PKM-personal-knowledge-mastery]] — 若强调个人知识流，Obsidian 常更贴近 PKM；若强调团队协作，Notion 更自然
