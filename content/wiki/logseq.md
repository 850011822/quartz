# Logseq

## 一句话定义

Logseq 是一个 local-first、block-first、outliner-first 的知识管理工具；和 Obsidian 相比，它更强调块引用、日记流和图数据库式组织。

## 它的典型气质

- journal-first
- block-based
- graph mindset
- 本地优先
- 更像思维大纲器，而不是传统文档编辑器

## Logseq vs Obsidian 的核心差异

| 维度 | Logseq | Obsidian |
| ---- | ------ | -------- |
| 基本单位 | block | file / note |
| 默认工作流 | journal / outline | page / vault |
| 写作感受 | 大纲优先 | 文档优先 |
| 扩展哲学 | 相对更内建 | 插件组合更自由 |

## 什么时候更偏向 Logseq

- 你以块为基本思考单位
- 你喜欢日记驱动的捕捉
- 你大量使用任务、块引用和层级折叠

## 什么时候更偏向 Obsidian

- 你更重视长文写作
- 你更在乎本地文件控制和插件组合自由
- 你想把 vault 进一步接到 [[quartz-static-site]]、Dataview、Templater 等生态里
