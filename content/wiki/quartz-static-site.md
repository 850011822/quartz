# Quartz Static Site

## 一句话定义

Quartz 是一个面向 markdown / digital garden 场景的静态站点生成器，能把 Obsidian 风格内容直接编译成带搜索、反链和图谱的网站。

## 为什么它在 Obsidian 生态里重要

官方把它定位为发布 personal notes、websites 和 digital gardens 的工具，而不是通用 CMS。

这意味着它天然重视：

- wikilinks
- backlinks
- graph view
- Obsidian compatibility
- 内容本地优先，再发布到 web

## Quartz 4 的特点

- batteries-included
- full-text search
- plugins 与自定义 layout
- hot reload 与增量构建
- 适合持续发布 markdown 知识库

## 它和 Publish 的不同感觉

Quartz 更像**可自托管、可 hack 的静态编译链**；你可以把它看成数字花园领域的工程化发布工具。

## 和其他概念的关系

- [[digital-garden]] — Quartz 是数字花园发布的代表实现之一
- [[公开第二大脑]] — 公开第二大脑通常需要一个发布层，Quartz 正好承担这层
- [[obsidian-ecosystem]] — Quartz 已成为 Obsidian 外部发布生态的重要一支
