# 公开第二大脑

## 一句话定义

把个人知识库的一部分**公开发布**到互联网，利用"Learn in Public"效应放大知识复利，同时倒逼自己把笔记写到可分享的质量。

## 为什么要公开（swyx 的论证）

| 论点 | 核心逻辑 |
| ---- | -------- |
| **Luck Surface Area** | 公开输出 → 更多人看到 → 更多随机好运气 |
| **Open Source Knowledge** | 一次整理多次引用 → 帮人时节省击键 → 知识复合增长 |
| **Digital Garden** | 比博客/社交媒体期望值低 → 可以放半成品 → 持续生长而不是一次性发表 |
| **Personal Content Warehouse** | 单一入口 → 自己和读者都不用记"放在哪" → 相关笔记更容易被发现 |

## 和 LLM Wiki 的关系

| 维度 | LLM Wiki (Karpathy) | 公开第二大脑 (swyx) |
| ---- | ---- | ---- |
| 受众 | **自己**（+ agent） | **自己 + 公众** |
| 写作者 | LLM 为主 | 人为主 |
| 发布 | 不发布 | Obsidian Publish / Quartz / 自建 |
| 核心价值 | 知识编译 + 累积 | 知识外显 + 社交复利 |

两者不矛盾：可以 wiki/ 内部由 LLM 维护，`public/` 子集由人审核后发布。

## 具体实现

swyx 的方案：

- **组织**：PARA
- **同步**：Obsidian Git（每 20 分钟自动）+ iCloud（移动端）
- **发布**：Obsidian Publish（$8/月），自定义落地页 + CSS
- **源码**：GitHub 仓库 `swyxio/brain`（PR 欢迎）

## 对你的启发

- 如果将来想让知识库的一部分对外展示，swyx 这条线是最直接的参考
- 最小方案：vault 里划一个 `public/` 分区 + frontmatter `published: true` + Quartz（免费）或 Obsidian Publish（付费）
- 记住 swyx 说的：不一定所有笔记都公开，他自己也保留部分在 Notion
